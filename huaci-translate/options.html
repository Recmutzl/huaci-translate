划词翻译

选中网页文字，即刻翻译成中文。API Key 只存在本机浏览器，不会上传。

基础设置

启用插件 关闭后选中文字不会触发任何操作
选中后自动翻译 关闭后：选中文字只出现「翻译」按钮，点击才翻译

翻译引擎

在 百度翻译开放平台 注册后，进入「管理控制台 → 开发者信息」即可看到 APP ID 和密钥。
在 DeepSeek 开放平台 →「API Keys」创建。按量计费，翻译场景费用极低。

联调测试

提示：① 短句翻译走上方所选引擎；② 划长段或点 toast 上的「翻译全文」会打开侧窗，全文/长文翻译固定使用 DeepSeek 大模型（保格式、支持整篇，按量计费，一次约几分钱），需确保上方已填写 DeepSeek API Key；③ 百度免费版每秒最多 1 次请求，连续快速选词会提示限流，属正常现象。
